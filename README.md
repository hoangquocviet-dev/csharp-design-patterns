# 🏛️ C# (.NET) Clean Architecture & Design Patterns Collection

A comprehensive collection of 50 practical, thread-safe, and production-ready **Gang of Four (GoF) Design Patterns** and **Enterprise Clean Architecture** implementations built with C# (.NET 8/9).

---

## 📚 Categorized Patterns

### 1. 🏗️ Creational Patterns
- **Singleton**: Thread-Safe Lazy Singleton, Double-Checked Locking
- **Factory Method**: Notification & Logger Creators
- **Abstract Factory**: Database & GUI UI Component Suites
- **Builder**: HTTP Request & SQL Query Fluent Builders
- **Prototype**: Deep-Clone Document Prototype
- **Object Pool**: High-performance Connection Pool

### 2. 🧩 Structural Patterns
- **Adapter**: Payment Gateway & Legacy XML-to-JSON Adapters
- **Bridge**: Remote Control & Graphics Renderer Bridges
- **Composite**: Hierarchical File System & Organization Trees
- **Decorator**: Caching, Logging & Compression Stream Decorators
- **Facade**: E-Commerce Order Processing & Media Converters
- **Flyweight**: Glyph Memory Optimization
- **Proxy**: Virtual Image Lazy Proxy & Role-based Protection Proxy

### 3. 🎯 Behavioral Patterns
- **Strategy**: Sorting, Dynamic Pricing & Validation Strategies
- **Observer**: Stock Market Ticker & Domain Event Broadcasters
- **Command**: Banking Transaction & Text Editor Undo/Redo
- **Chain of Responsibility**: HTTP Auth Pipeline & Expense Approval Handlers
- **Mediator**: Real-Time Chat & UI Dialog Mediators
- **Template Method**: ETL Data Ingestion & Report Generators
- **State**: Finite State Machine Order Flow & Audio Player
- **Memento**: Document History Snapshotting
- **Visitor**: Cart Tax Calculator & AST Evaluator
- **Iterator**: Binary Tree Depth-First Search Iterator

### 4. 🏢 Architectural Patterns
- **Generic Repository & Unit of Work**: Decoupled Data Access
- **Specification**: Strongly-Typed Business Rules
- **CQRS**: Command & Query Segregation
- **Functional Result Pattern**: Robust Exception-Free Error Handling
- **Strongly-Typed Options**: Validated Configuration
- **Middleware Pipeline**: ASP.NET Core-style Request Handlers
